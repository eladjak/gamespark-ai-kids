# GameSpark AI

אתר ווב אינטראקטיבי בעברית וב-RTL עבור פלטפורמה שבה ילדים יוצרים משחקים בעזרת בינה מלאכותית.

## 🔴 סטטוס — האתר באוויר, ואיש לא נגע בו מאז יוני

**https://gamespark-ai-kids.vercel.app — חי, ציבורי, ומחזיר 200.** אומת 11.8.2026.

הקומיט האחרון כאן הוא מ-14.6.2026, כלומר האתר משרת קהל כבר חודשיים בלי שאף אחד
בדק אותו. זה לא "פרויקט רדום" — זה **פרויקט לא מטופל**, וההבדל חשוב: דף רדום
לא יכול להביך אף אחד, ודף חי כן.

הפרויקט מקושר ל-Vercel דרך `.vercel/project.json` (`projectName: gamespark-ai-kids`),
ולכן דחיפה לענף הראשי מפרסמת לאוויר. **אין כאן `package.json`** — זה אתר
סטטי (HTML/CSS/JS), ו-Vercel מגיש אותו כמו שהוא.

**לפני שנוגעים בו שוב:** לפתוח את הכתובת החיה ולראות מה באמת מוצג שם היום,
לא להסתמך על מה שכתוב כאן. שני חודשים זה מספיק זמן לכך שהתוכן, הקישורים או
התמונות יתיישנו בלי שאיש ידווח.

**אח שלו:** `gamespark-math` — באותו מצב בדיוק (חי ב-`gamespark-math.vercel.app`,
קומיט אחרון 14.6.2026).

## מה יש בפרויקט

- סטודיו יצירה פעיל עם רעיון למשחק, בחירת ז'אנר, דמות ועולם.
- Canvas preview שמתעדכן לפי הבחירות של המשתמש.
- מצב טעינה מדומה ליצירת פרוטוטייפ.
- גלריית משחקים לדוגמה.
- אזור אמון להורים ולמורים.
- עיצוב רספונסיבי לדסקטופ ומובייל.

## הרצה מקומית

```bash
python -m http.server 4178
```

לאחר מכן לפתוח:

```text
http://127.0.0.1:4178
```

## קבצים חשובים

- `index.html` - מבנה האתר והתוכן בעברית.
- `styles.css` - שפת העיצוב, רספונסיביות ואנימציות.
- `script.js` - אינטראקציות הסטודיו וציור ה-Canvas.
- `gamespark-ai-home.png` - תמונת קונספט/צילום דסקטופ.
- `gamespark-ai-mobile.png` - צילום בדיקת מובייל.
